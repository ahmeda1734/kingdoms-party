# 👑 KINGDOMS PARTY

لعبة استراتيجية 2D أونلاينة تعمل على المتصفح — Real-Time Strategy مع الأصدقاء على خريطة واحدة، مستوحاة من Age of Empires وMini Kingdoms، بهوية كرتونية مبهجة.

## التشغيل

```bash
npm install
npm start          # http://localhost:8080
npm test           # 23 اختبار (محاكاة + شبكة حقيقية WebSocket)
```

## اللعب الآن (المرحلتان 1 و2)

1. افتح المتصفح على المنفذ، أدخل اسم مملكتك، وأنشئ غرفة.
2. شارك رمز الغرفة (أو رابط `/room/CODE`) مع أصدقائك ليدخلوا نفس الخريطة.
3. اضغط «أنا جاهز»، والمضيف يبدأ المعاينة.
4. اسحب للتجول، عجلة الفأرة/القرصة للتكبير.
5. اسحب تحديد فوق العمال (أو Shift+سحب لتحديد صندوقي، أو زر «كل العمال»)، ثم انقر على شجرة/صخرة/منجم/شجيرة لإتكليفهم — يدورون تلقائياً بين المورد والقلعة.
6. زر «📊 إحصائيات الاقتصاد» يعرض الأرصدة والإنتاج في الدقيقة وتوزيع العمال.
7. زر «🏗️ بناء» يفتح قائمة المباني: بيت سكان، مزرعة، مخزن، منشرة خشب، محجر، منجم ذهب، معمل طابوق. انقر على الزر ثم على الأرض لوضعه (سلالم البناء تظهر تقدماً حتى الاكتمال).
8. انقر على القلعة لفتح لوحتها وتدريب عامل جديد (50 🍎) — رأس المال السكاني يتوسع بالبيوت.
9. العمال المكلَّفون بمعمل الطابوق يحوّلون الحجر إلى طابوق ويعيدون الحمولة لأقرب مخزن أو للقلعة.

## البنية

- **Server Authoritative**: Node.js + `ws` (tick 15Hz) — سيرفر يحمل الحقيقة، عميل يرسل أوامر ويستقبل snapshots دلتا.
- **خريطة حتمية بنفس البذرة لكل اللاعبين** (`shared/mapgen.js`) + بصمة fingerprint للتحقق من التطابق.
- **ضباب الحرب سيرفري** لكل لاعب، مع بقية المناطق المكتشفة.
- كل شيء Canvas 2D مرسوم برمجياً (صفر أصول صور) — خفيف على الأجهزة والهواتف.

التفاصيل الكاملة: [docs/GDD.md](docs/GDD.md)

## الحالة: المرحلتان 1 + 2 (الأساس والاقتصاد/البناء) — منفذتان ومختبرتان

تم في المرحلة 1: هيكل المشروع، الخريطة (غابات/بحيرات/أنهار/جبال/مناجم/قرى موارد متوازنة)، الكاميرا، حركة العمال بأوامر واختيار، جمع الموارد ال4، غرف أونلاين حقيقية برموز دعوة، إعادة الاتصال برمز جلسة، ضباب حرب، خريطة مصغرة، لوحة إحصائيات، دردشة غرفة.

تم في المرحلة 2 (جديد): نظام بناء كامل بتحقق سيرفري (حدود/أرض صالحة/تصادم مع الموارد والمباني/تكلفة)، وقت بناء مع هيكل سقالات وشريط تقدم، 7 مبانٍ اقتصادية تعمل فعلاً: بيت (رأس سكاني +4)، مزرعة (طعام مستمر)، مخزن (نقطة إيداع ثانية +250 سعة)، منشرة/محجر/منجم (هالة +25% جمع ضمن 6 بلاطات)، معمل طابوق (تحويل الحجر → طابوق بعمّال مكلَّفين)، سعة تخزين مع فقد الفائض عند الامتلاء، تدريب العمال من القلعة (تكلفة + وقت + رأس سكاني)، سطر السكان والسعة في شريط الموارد والإحصائيات.

لم يُنفذ بعد (مصرّح): مستويات ترقية المباني، السوق والطاحونة والمباني التطويرية/الخاصة، وحدات القتال، العصور، AI، أنماط الفوز، الفرق، تداول الموارد بين اللاعبين — مرحلة 3–4.
